# Week 2 – Wireframes and GUI Design

## Pages Planned
1. Login Page – username, password, submit button
2. Register Page – username, email, password, confirm password
3. Dashboard – topbar, stats cards, quick actions
4. Add Student – full form with all fields
5. View Students – table with edit/delete actions
6. Edit Student – pre-filled form
7. Delete – confirmation prompt

## Technology Decisions
- Backend: PHP
- Database: MySQL via XAMPP
- Frontend: HTML5, CSS3, JavaScript
- Version Control: Git + GitHub

## Workflow
Auth system first → Dashboard → CRUD operations → Styling → Documentation
