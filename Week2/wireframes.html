🔄 Project Workflow

1. User registers → Data stored in users table

2. User logs in → Session created → Redirect to dashboard

3. Dashboard displays stats from students table

4. Add student → INSERT query → Shows success message

5. View students → SELECT query → Displays in table

6. Edit student → UPDATE query → Pre-fills form with existing data

7. Delete student → DELETE query → Confirmation popup first
